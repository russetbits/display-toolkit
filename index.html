DPCD 速查与解析 DP 链路

DPCD 寄存器地址速查（DP 2.1a）；粘贴 sink 的 DPCD dump 即可解析出链路能力、DSC / FEC / MST / 面板 replay 等能力摘要。

视频时序计算器 CEA-861 / VESA DMT

一行输入（4K60 / 1080i50 / VIC 97）即得完整时序：pixel clock、H/V 的 active/porch/sync/total、行频场频；并判定 HDMI TMDS 与 FRL 档位、DisplayPort 链路档位是否够用。

纯静态页面，无后端、无外部依赖。数据来源：EDID 样本取自 linuxhw/EDID 公开数据集；时序表依据 CEA-861 / VESA DMT / CVT / HDMI 2.1 / DP 2.1 规范。
